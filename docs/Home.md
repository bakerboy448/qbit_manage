# qBit Manage Wiki

qbit_manage manages qBittorrent: tags, categories, share limits, unregistered torrents, orphaned files, and rechecks.

## Get started

1. Install it.
   - [Desktop app, standalone binary, or Python](Installation)
   - [Docker](Docker-Installation)
   - [Unraid](Unraid-Installation)
2. [Set up your config file](Config-Setup). The desktop app and the [Web UI](Web-UI) edit it for you.
3. Pick the [commands](Commands) to run.
4. If you turn on the web server, read [Security](Security) first.
